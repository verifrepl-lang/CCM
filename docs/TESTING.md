# Чек-лист проверки (Этап 7 ТЗ)

Ручные сценарии для релиз-кандидата. Каждый пункт отмечается при проверке на реальном устройстве.

## 1. Чистая установка
- [ ] Установка APK из GitHub Releases (разрешить неизвестные источники)
- [ ] Первый запуск: экран входа Google
- [ ] Отказ входа → приложение не пускает дальше (данные не создаются)

## 2. Первый запуск без интернета
- [ ] Вход невозможен — показана явная ошибка сети, без имитации
- [ ] После входа с сетью и установленным окружением: airplane-mode → чаты, проекты, файлы, настройки, история терминала открываются
- [ ] Запрос к модели без сети → явная ошибка «Сеть недоступна», чат и редактор не закрываются, несохранённые изменения не теряются

## 3. Авторизация
- [ ] Google Sign-In проходит; повторный запуск восстанавливает сессию
- [ ] Выход очищает аккаунт; повторный вход под другим аккаунтом → пустые проекты/чаты (изоляция users/<hash>)
- [ ] API-ключи провайдеров не видны другому аккаунту

## 4. Окружение
- [ ] «Окружение» → установка: прогресс загрузки, проверка SHA-256, распаковка, статус «Готово»
- [ ] Прерывание загрузки (убить приложение) → повтор: докачка с того же места
- [ ] Повреждение: удалить filesDir/linux/rootfs/bin → «Восстановить» → работает, проекты не тронуты
- [ ] Лог установки просматривается, свободное место показывается

## 5. Проекты и файлы
- [ ] Создание проекта; создание/переименование/удаление файлов и каталогов (удаление — с подтверждением)
- [ ] Иконки языков: start.py → Python, App.tsx → TS-React, main.rs → Rust и т.д.
- [ ] Поиск по имени и содержимому
- [ ] Импорт ZIP и каталога через SAF; экспорт ZIP
- [ ] Редактирование файла в редакторе, сохранение, индикатор изменений

## 6. Терминал
- [ ] bash запускается (PRoot), `uname -a` → Debian
- [ ] `python3 --version`, `node --version`, `git --version` работают
- [ ] ANSI-цвета: `ls --color`, `vim`/`less` (alt-буфер)
- [ ] Несколько сессий, переключение, Ctrl+C, SIGTERM
- [ ] apt update/install проходит (при наличии сети)
- [ ] Перезапуск приложения: история команд восстановлена

## 7. ИИ
- [ ] Провайдер + ключ сохранены; активная модель выбрана
- [ ] Потоковая генерация видна в реальном времени
- [ ] Инструменты отображаются отдельными карточками; результат — отдельным блоком
- [ ] План (update_plan) отображается и обновляется
- [ ] propose_command → карточка подтверждения; «Отклонить»/«Разрешить» работают
- [ ] Режим Plan: запись файлов запрещена
- [ ] Остановка выполнения кнопкой «Остановить»
- [ ] Убить приложение во время выполнения → снова открыть чат → «продолжить» (контекст из БД)

## 8. MCP
- [ ] stdio-сервер (например `npx -y @modelcontextprotocol/server-filesystem /workspace`) подключается, инструменты видны
- [ ] HTTP-сервер подключается
- [ ] Ошибка подключения показывается; переподключение работает

## 9. Инструкции
- [ ] Настройки проекта → «Добавить файл инструкций» → SAF → README.md → файл появился в .crab/steering/
- [ ] Отключение файла инструкций
- [ ] .crab/CRAB.md подхватывается агентом

## 10. Ориентация и форм-факторы
- [ ] Портрет ↔ альбом: панели адаптируются, состояние сохраняется
- [ ] Планшет/landscape: NavigationRail
- [ ] Клавиатура: adjustResize, поле ввода не перекрывается

## 11. Уведомления
- [ ] Разрешение запрашивается при первом запуске задачи
- [ ] Звук/уведомление: задача выполнена, подтверждение, ошибка
- [ ] Индивидуальные переключатели в настройках работают

## 12. Обновления
- [ ] «Проверить сейчас» на актуальной версии → «обновлений нет»
- [ ] Новый релиз: версия, размер, SHA-256, changelog; скачивание с прогрессом; установка APK через системный установщик
- [ ] Пропуск версии работает
- [ ] Обновление окружения не затрагивает проекты

## 13. Изоляция пользователей
- [ ] Два аккаунта по очереди: разные проекты, чаты, ключи, MCP, терминальная история

## 14. Разные версии Android
