# Матрица совместимости с десктопным Crab-Code-IDE

Составлено по аудиту исходного кода `csanelo/Crab-Code-IDE` (v0.3.4, Electron + React + Monaco,
MIT). Статусы:

- ✅ **Без изменений** — концепт, формат или API сохранены как есть
- 🔁 **Адаптировано** — работает иначе, но с сохранением контракта/формата
- 🆕 **Отдельная реализация** — новый код для мобильной платформы
- ⛔ **Ограничено платформой** — невозможно или отложено, причина указана

## Архитектура

| Компонент оригинала | Реализация в мобильной версии | Статус |
|---|---|---|
| Electron main process (агент, интеграции) | Kotlin-слой `ai/`, `linux/`, `core/` | 🆕 (Electron не собирается под Android) |
| React renderer | Jetpack Compose в визуальном языке crab-dark | 🔁 |
| preload IPC-мост | Прямые вызовы Kotlin-модулей в общем процессе | 🔁 |
| Monaco editor | Редактор на Compose + regex-подсветка | 🔁 (Monaco — браузерный компонент) |
| xterm.js + node-pty | Собственный ANSI-эмулятор + JNI forkpty + PRoot | 🔁 |
| electron-store | DataStore + Room + JSON-конфиги | 🔁 |
| Темы themes.ts (crab-dark и др.) | CrabTheme с точными цветами crab-dark/light | ✅ |
| i18n (9 локалей, ru) | Русский интерфейс по умолчанию, структура готова | 🔁 |

## Итоговые ограничения платформы (сформулированы явно)

1. **targetSdk 28** — обязательное условие exec() из data-каталога для PRoot (как Termux);
   приложение не предназначено для Google Play.
2. **Фоновая работа** ограничена Android: интерактивные процессы умирают вместе с приложением;
   продолжительные задачи агента идут под foreground-уведомлением в пределах отведённого времени.
3. **Плагины Node.js-формата** не исполняются (нет Node-рантайма в главном процессе) — задокументировано,
   фиктивной поддержки нет.
4. **Kiro/LSP/SSH/GitHub-инструменты** — вне версии 1.0.6 по приоритетам портирования.
