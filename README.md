# Crab-Code-IDE Mobile

**Crab-Code-IDE** — полноценная мобильная IDE для Android с интегрированным ИИ-агентом,
Linux-окружением (Debian 12 + PRoot), терминалом, файловым менеджером и поддержкой MCP.
Мобильный порт проекта [Crab-Code-IDE](https://github.com/csanelo/Crab-Code-IDE) (Electron + React + Monaco),
сохраняющий его визуальный язык, агентскую архитектуру, форматы скиллов и инструкций, каталог провайдеров
и оригинальные графические ресурсы.

## Возможности

- **Нативный Android-интерфейс** на Jetpack Compose в визуальном стиле CrabCode (тема crab-dark
  с точными цветами оригинала, светлая тема, масштабирование текста, портрет/альбом/планшет).
- **Linux-окружение Debian 12 (bookworm)** через PRoot: настоящий userspace с bash, python3, node,
  npm, git, apt — без root-доступа на устройстве.
- **Настоящий терминал**: собственный ANSI/VT-эмулятор (16/256/RGB-цвета, альтернативный буфер,
  scrollback), PTY через JNI (`forkpty`), несколько параллельных сессий, история команд,
  Ctrl+C/Z/D, сигналы, размер шрифта, отдельная консоль вывода агента.
- **ИИ-агент** с циклом выполнения как в оригинале: сбор контекста → выбор инструментов →
  выполнение в рамках политики → потоковая передача прогресса → представление изменений.
  Режимы **Agent / Plan / Ask**.
- **Потоковый чат**: текст и «размышления» модели в реальном времени, вызовы инструментов и их
  результаты, план выполнения, статусы, изменения файлов, ошибки и **запросы подтверждения** —
  каждый элемент отображается отдельным блоком интерфейса.
- **Инструменты агента**: чтение/запись/правка файлов, поиск, листинг, команды в Linux-окружении
  (`run_command` / `propose_command` с подтверждением), план, память проекта (`.crab/MEMORY.md`),
  скиллы (`.crab/skills/<имя>/SKILL.md`), `fetch_url`, MCP-инструменты.
- **Провайдеры моделей**: OpenAI-совместимые API, Anthropic Messages, Google Gemini, OpenRouter,
  Mistral, DeepSeek, Groq, Cerebras, Together, Fireworks, Perplexity, Cohere, xAI, Moonshot,
  GitHub Models, Hugging Face, OpenCode (бесплатные модели), а также любые custom-эндпоинты.
- **MCP**: stdio-серверы запускаются в Linux-окружении, HTTP/SSE — напрямую; JSON-RPC 2.0,
  список инструментов, статус подключения, переподключение, изоляция сбоев.
- **Файловый менеджер**: дерево проекта, оригинальные SVG-иконки языков (230+ иконок из
  Crab-Code-IDE: Python, JS, TS, Rust, Go, HTML, CSS, JSON и т.д.), поиск по именам и
  содержимому, создание/переименование/удаление/перемещение, импорт ZIP и каталогов,
  экспорт ZIP (через Android Storage Access Framework).
- **Редактор кода** с подсветкой синтаксиса (Python, JS/TS, Kotlin, Rust, Go, Java, shell и др.).
- **Google Sign-In** (обязательный вход): проверка ID-токена по JWKS Google, изоляция проектов,
  чатов, терминальных сессий, ключей API и MCP-конфигураций по аккаунтам.
- **Офлайн-режим**: история чатов, проекты, файлы, настройки, история терминала и предыдущие
  ответы ИИ доступны без сети; недоступность провайдера показывается явно, генерация не имитируется.
- **Уведомления и звуки**: завершение задачи, запрос подтверждения, ошибки, исчерпание квоты,
  установка окружения — с индивидуальными переключателями.
- **OTA-обновления**: проверка версий через GitHub Releases, SHA-256, докачка загрузки,
  обновление APK и Linux-окружения по отдельности.
- **Инструкции для ИИ**: формат оригинала `.crab/CRAB.md` + `.crab/steering/*.md`; через системный
  пикер документов подключаются `README.md`, `AGENTS.md` и другие файлы.

## Установка

1. Откройте **Releases** этого репозитория (см. ссылку ниже).
2. Скачайте `CrabCodeMobile-v<версия>.apk` и `.sha256`.
3. Проверьте контрольную сумму:
   ```bash
   sha256sum -c CrabCodeMobile-v1.0.6.apk.sha256
   ```
4. Установите APK на устройство (разрешите установку из этого источника, когда Android спросит).
5. При первом запуске войдите через Google и нажмите **«Установить»** в разделе «Окружение» —
   приложение само скачает Debian-rootfs для архитектуры устройства (~150 МБ) с проверкой SHA-256
   и поддержкой докачки.

> PRoot **не даёт** настоящих привилегий суперпользователя: «root» внутри окружения — эмуляция
> в пользовательском пространстве. Все данные остаются в приватном каталоге приложения.

## Сборка через GitHub Actions

Репозиторий содержит полный CI/CD:

- **`.github/workflows/ci.yml`** — на каждый push/PR: юнит-тесты + сборка debug-APK.
- **`.github/workflows/release.yml`** — на тег `v*`: сборка rootfs (arm64 на arm-раннере,
  x86_64 на обычном), загрузка проверенных PRoot-бинарников из репозитория Termux, подпись APK,
  юнит-тесты, генерация `env-manifest.json` и публикация GitHub Release со всеми артефактами.
- **`.github/workflows/rootfs.yml`** — ручное пересобирание Linux-окружения без релиза приложения.

Локальная сборка:

```bash
git clone <этот-репозиторий>
cd crab-code-ide-mobile

# PRoot-бинарники (нужны для терминала и MCP-stdio):
scripts/fetch-proot.sh aarch64
scripts/fetch-proot.sh x86_64

gradle :app:assembleDebug   # Gradle 8.9, JDK 17
```

Никаких ручных изменений файлов на компьютере разработчика не требуется: CI делает всё сам.

### Подпись релизного APK

CI по умолчанию подписывает релиз debug-ключом, чтобы APK можно было сразу установить.
Для собственной подписи создайте `keystore.properties` в корне:

```properties
storeFile=/путь/к/keystore.jks
storePassword=***
keyAlias=crabcode
keyPassword=***
```

и добавьте секреты `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`
в GitHub Secrets, если хотите подписывать прямо в CI. Приватные ключи в исходный код не добавляются.

## Настройка Google OAuth

1. Откройте [Google Cloud Console → Credentials](https://console.cloud.google.com/apis/credentials).
2. Создайте **OAuth client ID → Web application** (Credential Manager на Android использует
   веб-клиент с проверкой ID-токена).
3. Скопируйте client id вида `1234...apps.googleusercontent.com`.
4. Вставьте его в файл `app/src/main/assets/google_client_id.txt` (одна строка).
5. Вход выполняется через официальную библиотеку Credential Manager (`androidx.credentials` +
   `com.google.android.libraries.identity.googleid`); ID-токен проверяется локально по
   JWKS Google (`https://www.googleapis.com/oauth2/v3/certs`): подпись RS256, `iss`, `aud`, `exp`.

Никакой серверной части не требуется — приложение полностью локальное.

## Linux-окружение и PRoot

- **Rootfs**: Debian 12 (bookworm), собирается в CI через `docker export` с предустановленными
  `python3`, `pip`, `node`, `npm`, `git`, `build-essential`. Артефакты для arm64 и x86_64
  публикуются в Releases с SHA-256 в `env-manifest.json`.
- **PRoot**: проверенные бинарники из репозитория пакетов Termux (`proot` + `libtalloc`),
  пинненные версии, размещаются в APK как native-библиотеки (`libproot.so`, `libtalloc.so`).
- Окружение устанавливается при первом запуске в приватный каталог приложения, переживает
  перезапуски, обновляется отдельно от APK и **не затрагивает** проекты пользователя.
- **Почему targetSdk 28**: начиная с Android 10 приложения с targetSdk ≥ 29 не могут запускать
  исполняемые файлы из своих data-каталогов (W^X), что ломает PRoot-окружения. Точно так же
  поступает Termux. Приложение распространяется через GitHub Releases, а не Google Play, поэтому
  политика Play по targetSdk не применяется. Подробнее: `docs/COMPATIBILITY.md`.

## Модели и провайдеры

Раздел «Модели»: каталог провайдеров оригинала (OpenAI, Anthropic, Google Gemini, OpenRouter,
Mistral, DeepSeek, Groq, Cerebras, Together, Fireworks, Perplexity, Cohere, xAI, Moonshot, GitHub
Models, Hugging Face, OpenCode, свои OpenAI-совместимые эндпоинты). Для каждого провайдера:

- API-ключ хранится в зашифрованном хранилище (EncryptedSharedPreferences, AES-256-GCM) и
  привязан к аккаунту пользователя;
- активная модель выбирается чипом — как переключение провайдера/модели в десктопном CrabCode.

Семейства API: `openai` (chat/completions, SSE, function calling), `anthropic` (Messages API,
SSE, tool_use), `gemini` (streamGenerateContent, functionDeclarations).

## MCP и расширения

Раздел «MCP»:

- **stdio**-серверы запускаются внутри Linux-окружения (например
  `npx -y @modelcontextprotocol/server-filesystem /workspace`);
- **HTTP (Streamable HTTP/SSE)** — прямое подключение;
- список инструментов каждого сервера, статус, ошибки подключения, повторное подключение;
- инструменты подключённых серверов автоматически появляются у агента с префиксом
  `mcp__<сервер>__<инструмент>` и подлежат тем же подтверждениям, что и встроенные.

Плагины десктопного формата (`.crab-plugin/plugin.json`) в мобильной версии 1.0.6 не загружаются —
см. `docs/COMPATIBILITY.md` (ограничение и план). Проектные скиллы `.crab/skills/` работают.

## Системные требования

- Android 8.0 (API 26) или новее;
- arm64 (обычные телефоны/планшеты) или x86_64 (эмуляторы);
- ~500 МБ свободного места (приложение + Linux-окружение);
- 3–4 ГБ ОЗУ рекомендовано (PRoot + редактор + чат).

## Устранение неполадок

| Проблема | Решение |
|---|---|
| «Не настроен Google OAuth client id» | Заполните `app/src/main/assets/google_client_id.txt` |
| Окружение не устанавливается | Раздел «Окружение» → проверьте свободное место, лог установки; повторите загрузку (докачка продолжится) |
| Терминал: «Linux-окружение не установлено» | Установите окружение в разделе «Окружение» |
| ИИ не отвечает | Проверьте API-ключ и выбранную модель; при отсутствии сети провайдер недоступен — это отображается явно |
| MCP-сервер не подключается | stdio-сервер требует установленного окружения (node/npx); HTTP — доступности URL |
| «Путь вне песочницы проекта» | Агент работает только внутри активного проекта — так задумано |
| После перезагрузки устройства сессии теряются? | Чаты и проекты сохранены; интерактивные процессы терминала продолжить нельзя (ограничение Android), но история команд сохранена |

## Диагностика сбоев

Если приложение вылетает:

1. Обновитесь до актуального релиза — в сборке 1.0.6 был включён R8-минификатор,
   из-за которого возможен краш при запуске; начиная с 1.0.7 он отключён.
2. При любом сбое полный stack trace пишется в файл
   `/sdcard/Android/data/com.crabcode.ide.mobile/files/crash_log.txt`
   (виден любым файловым менеджером). На экране входа также появляется кнопка
   «Отправить лог последнего сбоя».
3. Вход без Google: кнопка «Продолжить локально (без Google)» создаёт
   локальный профиль с тем же изолированным пространством данных.
   Google-вход заработает после добавления OAuth Web client id в
   `app/src/main/assets/google_client_id.txt`.
